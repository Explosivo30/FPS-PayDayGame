[BUGFIX]
  - Eliminado LayerNames/GetLayerName duplicado (causaba CS0111)

[FEATURE] Preview de mazmorra en tiempo real
  Panel "🗺 PREVIEW MAZMORRA" en la esquina inferior izquierda del canvas.
  Se actualiza al soltar el ratón después de pintar.
  Estilo top-down papel D&D:
    · Fondo papel envejecido (beige)
    · Grid azul pálido de fondo
    · Suelo de habitación con sombra interior
    · Paredes dibujadas como líneas gruesas oscuras
    · Pasillos como corredores entre nodos
    · Nodos como puntos
    · Capas no activas aparecen más tenues
    · Escala en metros en la esquina del panel
    · Botón ▼/▲ para colapsar el panel

[FEATURE] Convertir a ProBuilder
  Botón "⬡ Convertir a ProBuilder" en la barra inferior.
  Convierte toda la jerarquía generada a ProBuilderMesh de una vez.
  Permite editar vértices, bordes y caras directamente en ProBuilder.

  REQUISITOS:
  1. Window → Package Manager → Unity Registry → ProBuilder → Install
  2. Project Settings → Player → Scripting Define Symbols:
     Añadir: PROBUILDER_AVAILABLE
  Sin el define, el botón muestra instrucciones de instalación.
